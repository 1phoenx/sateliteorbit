## 4. 使用训练好的模型进行预测

### 4.1 加载模型并预测

```python
import numpy as np
from src.final_model import ManeuverDetectionSystem

# 初始化系统（阈值0.2可提高召回率）
system = ManeuverDetectionSystem(threshold=0.2)

# 加载预训练模型
system.load("models")

# 准备测试数据 (P, T, R)
# P: 尾焰辐射峰值强度
# T: 尾焰持续时间（秒）
# R: 光谱强度比（226nm/306nm）
X_test = np.array([
    [1.5, 300.0, 15.0],   # 样本1
    [0.8, 150.0, 8.0],    # 样本2
    [2.0, 450.0, 20.0],   # 样本3
])

# 预测
result = system.predict(X_test)

# 输出结果
for i in range(len(X_test)):
    print(f"样本 {i+1}:")
    print(f"  是否变轨: {'是' if result['is_maneuver'][i] else '否'}")
    print(f"  变轨概率: {result['maneuver_probability'][i]:.4f}")
    print(f"  点火时刻: {result['ignition_time'][i]:.2f}s")
```
